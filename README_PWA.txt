MALLIGA GARDEN ACCOUNTS - PWA

1. Host this folder over HTTPS (or use localhost for testing).
2. Open index.html from the hosted address on Android Chrome.
3. Choose Install App / Add to Home screen.
4. The app opens in standalone mode and stores accounting data locally in the browser on that device.
5. Keep using Backup Data regularly.

WhatsApp:
- Each receipt has a WhatsApp share action. On Android, the native share sheet can attach the receipt image.
- Resident statements can be printed/saved as PDF and then shared to the resident's WhatsApp chat.
- WhatsApp does not permit a PWA to silently send different private files to 12 chats in one tap. The WhatsApp Center therefore uses a safe one-resident-at-a-time workflow.
